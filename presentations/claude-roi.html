The Standard

12 Rules. Zero Ambiguity.

Rules 1–4 from the Claude Code research baseline (Jan 2026). Rules 5–12 cover May 2026 agent problems: token runaway, silent failures, multi-step drift. Past 12 rules, compliance drops. These 12 cover 97% of failure modes.

1
Think Before Coding
State assumptions. Ask rather than guess. Push back on complexity.
2
Simplicity First
Minimum code. No speculation. No abstractions for single-use code.
3
Surgical Changes
Touch only what you must. Don't improve adjacent code.
4
Goal-Driven Execution
Define success criteria. Loop until verified.
5
Model for Judgment Only
AI for classification/drafting. Code for routing/retries/transforms.
6
Token Budgets
4k tokens/task. 30k/session. Surface breach, don't overrun.
7
Surface Conflicts
Pick one pattern. Explain why. Flag the other. Never blend.
8
Read Before Write
Read exports, callers, utilities before adding code.
9
Tests Verify Intent
Tests must fail when business logic changes. Not just coverage.
10
Checkpoint Every Step
Summarise done/verified/left. Stop if state is unclear.
11
Match Conventions
Conformance over taste. Surface disagreement, don't fork silently.
12
Fail Loud
"Completed" is wrong if anything was skipped. Default to surfacing uncertainty.
